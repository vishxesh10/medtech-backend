# Railway Deployment Guide - Step by Step

## Step 1: Create Railway Project

1. Go to [Railway.app](https://railway.app)
2. Sign in with GitHub
3. Click **Create New Project**
4. Select **Deploy from GitHub repo**
5. Select `medtech-backend` repository

## Step 2: Add PostgreSQL Database

1. In Railway dashboard, click **+ Add a Service**
2. Search for **PostgreSQL**
3. Click **PostgreSQL**
4. Click **Create**

Railway will automatically generate the `DATABASE_URL` environment variable.

## Step 3: Set Environment Variables

Go to **Variables** tab and add these:

### 🔴 Required Variables

```
JWT_SECRET_KEY=your-long-random-secret-key-here-at-least-32-characters
```

Generate a secure key:
```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

### 🟡 API Keys (Get from respective services)

```
GEMINI_KEY=your-google-gemini-api-key-here
```

To get Gemini API key:
- Go to [Google AI Studio](https://aistudio.google.com/apikey)
- Create a new API key
- Copy and paste here

### 🟠 Optional Variables

```
HF_TOKEN=your-huggingface-token-here
API_BEARER_TOKEN=optional-bearer-token
```

### 🟢 CORS Settings

```
CORS_ALLOW_ORIGINS=["https://your-frontend-domain.com"]
```

Replace with your actual frontend domain:
- If using Vercel: `https://your-project-name.vercel.app`
- If using Netlify: `https://your-site-name.netlify.app`

## Step 4: Configure Auto-Deploy

1. Go to **Settings** tab
2. Enable **Auto-Deploy on Push**
3. Select branch: `main`

## Step 5: Connect Frontend

In your frontend environment variables (Vercel/Netlify):

```
VITE_API_BASE_URL=https://your-railway-backend-url
```

Get your Railway backend URL:
1. Go to Railway dashboard
2. Click on your service
3. Copy the **URL** (looks like `https://medtech-backend-prod-abc123.railway.app`)

## Step 6: Verify Deployment

Once deployed:

```bash
# Check health
curl https://your-railway-backend-url/health

# Check version
curl https://your-railway-backend-url/version
```

## Environment Variables Reference

| Variable | Required | Example | Description |
|----------|----------|---------|-------------|
| `DATABASE_URL` | ✅ | Auto-generated by Railway | PostgreSQL connection string |
| `JWT_SECRET_KEY` | ✅ | `your-secure-random-key` | Secret for JWT tokens (change!) |
| `GEMINI_KEY` | ✅ | From Google AI Studio | Google Gemini API key |
| `CORS_ALLOW_ORIGINS` | ❌ | `["https://yourdomain.com"]` | Allowed frontend domains |
| `HF_TOKEN` | ❌ | Hugging Face token | For model downloads |
| `API_BEARER_TOKEN` | ❌ | Custom token | Optional API security |

## Troubleshooting

### Build Fails
- Check Railway build logs
- Ensure `pyproject.toml` and `uv.lock` are present
- Verify Python version is 3.10+

### Database Connection Error
- Verify `DATABASE_URL` is automatically set
- Click **PostgreSQL** service to see connection details
- Test connection in Railway logs

### API Returns 500 Errors
- Check Railway logs
- Verify all required environment variables are set
- Check `JWT_SECRET_KEY` is strong and at least 32 chars

### Frontend Can't Connect
- Check `CORS_ALLOW_ORIGINS` includes frontend domain
- Verify frontend `VITE_API_BASE_URL` is correct
- Test with `curl` first

## Getting Railway Backend URL

1. Dashboard → Select your backend service
2. Top right, copy the **URL**
3. Use this in frontend `VITE_API_BASE_URL`

Example: `https://medtech-backend-prod-xyz.railway.app`

## Auto-Deploy

- Every push to `main` automatically redeploys
- Watch deployment in **Deployments** tab
- Logs available in **Logs** tab
